# SP CopyFromRSN

Revit add-in для пакетного копирования моделей между **Revit Server Network (RSN)** и обычной файловой структурой (локальные диски / UNC).

Плагин открывает безмодальное окно, позволяет хранить профили переноса, импортировать списки из CSV, опционально переназначать связи и запускать копирование моделей между ревит-серверами вручную или по расписанию.

## Возможности

- Копирование моделей **RSN → RSN**, **RSN → файлы**, **файлы → RSN**, **файлы → файлы**
- Профили настроек с сохранением на диск
- Импорт / экспорт списка моделей в CSV (совместимость с макросом / Dynamo)
- Опциональная замена путей связанных файлов (RepathLinks)
- Подавление предупреждений при пакетном открытии моделей
- Расписание по дням недели и времени ПК (пока открыто окно плагина)
- Журнал выполнения в папке загрузки

## Как открыть

В Revit: вкладка **Дополнения** → панель **Копирование RSN** → **Копирование с RSN**.

## Использование

### Профили

В верхней части окна можно создать, сохранить, переименовать и удалить профиль.

Профили хранятся здесь:

```text
%AppData%\Autodesk\Revit\Addins\{version}\SP_CopyFromRSN\Configs\
```

Активный профиль:

```text
%AppData%\Autodesk\Revit\Addins\{version}\SP_CopyFromRSN\active-profile.txt
```

### Вкладка «Общие»

| Параметр | Назначение |
|---|---|
| **Папка загрузки** | Рабочая папка для локальных копий, логов и state-файла расписания |
| **RevitServerTool** | Путь к `RevitServerTool.exe` (нужен только если источник — RSN). Обычно: `C:\Program Files\Autodesk\Revit {year}\RevitServerToolCommand\RevitServerTool.exe` |
| **RepathLinks** | Перед сохранением заменить пути связей по таблице на вкладке «Связи» |
| **Подавлять предупреждения** | Автоматически закрывать диалоги Revit при пакетном открытии (апдейтеры, потеря элементов при импорте и др.) |

### Вкладка «Модели»

Для источника и цели есть отдельные галочки **Revit Server** и поля сервера (`IP:порт`).

| Галочка | Поведение |
|---|---|
| Включена | Поле сервера активно; относительные пути на RSN собираются через этот сервер |
| Выключена | Поле сервера неактивно; относительные RSN-пути для этой стороны не принимаются |

В таблице указываются исходный и целевой пути. Поддерживаются форматы:

| Тип пути | Пример | Когда нужен сервер |
|---|---|---|
| Относительный RSN | `Проект/Модель.rvt` | Да — включите **Revit Server** и укажите сервер |
| Полный RSN | `RSN://host:port/Проект/Модель.rvt` | Нет — сервер берётся из пути |
| Файловый / UNC | `C:\Models\Модель.rvt`, `\\server\share\Модель.rvt` | Нет |

Имена файлов моделей в списке должны быть уникальны.

### Вкладка «Связи»

Доступна при включённом **RepathLinks**.

| Колонка | Описание |
|---|---|
| **Модель** | Имя файла модели из списка (например `Модель.rvt`) |
| **Старый путь** | Текущий путь связи в модели |
| **Новый путь** | Новый путь (RSN или файловый) |

Для файловых новых путей используется абсолютный тип пути, для RSN — серверный.

### Вкладка «Расписание»

- Включение автозапуска
- Дни недели и одно или несколько времён (`ЧЧ:ММ`)
- Время — **локальные часы компьютера**
- Автозапуск работает **только пока открыто окно плагина**
- Опоздавший слот (более ~10 минут) пропускается; повторный запуск того же слота блокируется через `{папка загрузки}\RSNCopyMacro.state`

### CSV

- **Импорт CSV… / Экспорт CSV** — список моделей (`SourcePath;TargetPath`)
- При импорте полные `RSN://host/...` разбираются: host попадает в поля серверов, в таблице остаётся относительный путь
- Кодировки UTF-8 / UTF-16 / ANSI определяются автоматически

### Запуск

Кнопка **Запустить сейчас**:

1. Проверяет настройки профиля
2. Сохраняет профиль
3. Для каждой модели готовит локальную копию:
   - из RSN — через `RevitServerTool createLocalRVT`
   - из файловой системы — через копирование файла
4. При необходимости переназначает связи
5. Отсоединяет модель и сохраняет её как центральную по целевому пути

Статус отображается в окне и пишется в журнал:

```text
{папка загрузки}\CopyFiles2RSN_yyyy-MM-dd.log
```

Старые логи старше 14 дней удаляются автоматически.

## Установка

### EXE-инсталлятор (рекомендуется)

1. Соберите установщик (см. [Сборка установщика](#сборка-установщика)) или возьмите готовый `dist\SP_CopyFromRSN-{version}-Setup.exe`
2. Запустите Setup
3. Выберите нужные версии Revit (2022 / 2023 / 2025 / 2026)
4. Перезапустите Revit

Файлы устанавливаются в:

```text
%AppData%\Autodesk\Revit\Addins\{year}\
```

### Ручная установка

После сборки конфигурации:

```powershell
.\dist\R2023\Install-Standalone.ps1
```

Скрипт очищает старые файлы плагина для этой версии Revit и копирует актуальные. Затем перезапустите Revit.

## Сборка плагина

### Требования

- [Visual Studio](https://visualstudio.microsoft.com/) или [.NET SDK](https://dotnet.microsoft.com/download)
- Установленный Autodesk Revit нужной версии (для ссылок на Revit API)
- Для EXE-установщика — [Inno Setup 6](https://jrsoftware.org/isinfo.php)

### Конфигурации

| Конфигурация | Revit | Target Framework |
|---|---|---|
| `R2022` | 2022 | `net48` |
| `R2023` | 2023 | `net48` |
| `R2025` | 2025 | `net8.0-windows` |
| `R2026` | 2026 | `net8.0-windows` |

### Сборка из Visual Studio

1. Откройте `SP_CopyFromRSN.sln`
2. Выберите конфигурацию (`R2022` / `R2023` / `R2025` / `R2026`)
3. Build → Build Solution

После успешной сборки DLL и `.addin` копируются в `dist\R{year}\` и обычно сразу в `%AppData%\Autodesk\Revit\Addins\{year}\`.

### Сборка из командной строки

Одна версия:

```powershell
dotnet build SP_CopyFromRSN.sln -c R2023
```

Другие версии:

```powershell
dotnet build SP_CopyFromRSN.sln -c R2022
dotnet build SP_CopyFromRSN.sln -c R2025
dotnet build SP_CopyFromRSN.sln -c R2026
```

### Сборка установщика

Из корня репозитория:

```powershell
.\build\Build-Installer.cmd
```

или:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build\Build-Installer.ps1
```

Скрипт:

1. Собирает все конфигурации (`R2022`–`R2026`)
2. Формирует `dist\R20XX\`
3. Генерирует Inno Setup-скрипт
4. Собирает `dist\SP_CopyFromRSN-{version}-Setup.exe`

Полезные ключи:

```powershell
# только упаковка, без пересборки проектов
.\build\Build-Installer.ps1 -SkipBuild

# только подготовка dist / .iss, без ISCC
.\build\Build-Installer.ps1 -SkipInstaller
```

## Структура репозитория

```text
SP_CopyFromRSN/
├── App/                 # точка входа add-in, лента
├── Assets/              # иконки
├── Models/              # модели профиля и строк таблиц
├── Revit/               # ExternalEvent, runtime, подавление предупреждений
├── Services/            # копирование, профили, CSV, расписание
├── UI/                  # WPF-окно и ViewModel
├── build/               # скрипты сборки дистрибутива
├── InnoSetup/           # шаблон установщика
├── dist/                # выходные сборки и Setup.exe
└── LICENSE
```
